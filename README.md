# 野人量化 · yeren-tide

把一套 A 股短线交易体系做成能算、能看的手机工具。纯本地运行——无后端、无账号、无广告，不收集任何数据。

潮水退去才知道谁在裸泳。这个工具算的是**潮水退到了哪一层**，以及在这个水位下该不该下水。

`yeren` 是这套方法的名字：不预测、不解释、只跟随。`tide` 是它真正研究的东西——情绪潮汐。
涨停梯队是浪高，两市量能是潮位，退潮期的仓位上限就是水退到哪一步。

---

## 它回答四个问题

| 问题 | 答案在哪 |
|---|---|
| **今天能不能做** | 市场页：情绪温度计、两市量能、高度天花板 |
| **做哪只** | 选股页：短线池 / 波段池；板块榜 → 板块内个股排名 |
| **买多少** | 风控页：按情绪阶段自动给出仓位上限 |
| **亏在哪** | 个股页：止损价、目标价、该退出的理由 |

## 五个页面

### 市场
指数、两市量能、情绪温度计、涨停梯队、板块涨停榜。

量能不只给一个数字：水位（绝对成交额）、中枢（60 日均量在上移还是下移）、位置（近 120 日分位）、
性质（缩量跌 / 缩量涨 / 放量跌 / 放量涨）。月度均量画成柱状图，半年台阶下移一眼可见。

涨停梯队点数字展开个股。板块榜点进去看二级页——板块内个股按**审美**排序：
同一板块里资金最先想到谁，谁就是龙头。

### 选股
短线池按六维打分（身位 / 人气 / 封单 / 封板时间 / 换手 / 板块），带否决项（ST、市值、换手不足）。
波段池扫月线资金流，标出符合买点的位置。

### 持仓
成本、止损、仓位、浮动盈亏。当前情绪阶段不允许的仓位会直接提示。

### 风控
仓位刻度、各阶段上限、每日执行清单、黑名单。把「什么时候不做什么」写死在界面里，
比记在脑子里可靠。

### 个股
默认分时，可切日 K（右侧叠加筹码分布：红为获利盘、蓝为套牢盘）。顶部决策卡先给结论，
再给止损 / 目标 / 仓位；下面依次是主力成本与偏离、涨停基因（近一年涨停次数与次日溢价）、
相对强弱、压力支撑。

## 说明

数据来自腾讯行情、东方财富、新浪财经的公开接口，不需要任何 key，也不需要注册。

所有指标是对交易体系的规则化归纳，不是原文照录。本工具不构成投资建议。

超短不适合大多数人——这一点原作者本人反复强调。一年 250 个交易日，绝大多数是无效交易；
能在 90% 的无效时间里不亏不赚，已经是高手。股市有风险，入市需谨慎。
